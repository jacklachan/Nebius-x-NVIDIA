How it works

  1. TriageNemotron Nano picks each lookup: logs, traces, commits, configs.
  2. DiagnosisNemotron Ultra reads the evidence and names the cause and how it spread.
  3. ResearchSearches published guidance, with nothing internal in the query.
  4. PostmortemNemotron Super writes it. Facts and citations are assembled in code.
