# Hindsight

Investigates a production incident from its telemetry, names the root cause
and writes the postmortem, with every claim tied to the evidence behind it.
Runs on NVIDIA Nemotron models served by Nebius Token Factory.

Source, setup and documentation: https://github.com/jacklachan/Nebius-x-NVIDIA

This Space is deployed from the GitHub repository with `space/deploy.sh`;
change the code there, not here.
